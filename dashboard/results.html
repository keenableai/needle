NEEDLE is an open-source benchmark of web search APIs for AI agents, run by Keenable. Each engine gets the same queries in {{VERTICAL_COUNT}} verticals: {{VERTICALS}}. An LLM judge or a match against known answers scores the top results of each engine. A score is the share of the best result list that all engines found together, so 100% is the ceiling.

overall
